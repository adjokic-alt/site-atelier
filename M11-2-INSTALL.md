# M11.2 Home Page

Copy the complete `src` folder over the existing M11.1 project and choose Replace files in destination.

The home page includes:
- hero with Style Quiz and Inquiry CTAs
- key product facts
- four-step explanation
- three featured style cards
- service/scope explanation without unsupported promises
- clear demo/local-storage wording
- final conversion section
- page-specific metadata

No real project photography is claimed. The hero uses a designed illustrative gradient until licensed or owned photography is added later.

Run:
```powershell
npm run lint
npx tsc --noEmit
npm run build
npm run dev
```

Open `/` and test at 390px, 768px, 1024px and desktop widths. Verify all CTAs, keyboard focus, Header overlap, and that the style cards open their Studio pages.
