# M7 Complete Style Studios

Copy the complete `src` folder over the existing project and choose Replace files in destination. No manual editing is required.

Adds complete data-driven Studio pages for:
- Modern
- Minimalist
- Industrial
- Luxury
- Rustic
- Mediterranean

Scandinavian is also routed through the shared Studio component.

Run:
```powershell
npm run lint
npx tsc --noEmit
npm run build
npm run dev
```

Verify all `/styles/[style]` routes, style-specific accents, material selection, Brief persistence, and quiz-result navigation.
